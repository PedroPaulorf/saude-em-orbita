Selo que diz de onde vem um dado ou uma regra.

- `h7-badge--simulated`: valores de saúde fictícios. Em toda tela que os mostra.
- `h7-badge--demo`: regra de alerta criada pela equipe, sem fonte clínica. Ao lado de toda sinalização.
- `h7-badge--live`: dado real da NASA (DONKI, textos do HRP), junto de um link para a fonte.

Não tem ícone, para não se confundir com o selo de estado.
