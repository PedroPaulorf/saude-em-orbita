Cartão de clima espacial com eventos do DONKI, ligado ao risco de radiação.

Quem usa fornece a lista de eventos: código (`FLR`, `SEP`), descrição curta e horário em UTC. Sempre com o selo `h7-badge--live`, o link para a fonte e a frase que declara o limite: o DONKI informa eventos solares, não a dose recebida. Sem evento recente, diga isso em uma linha; não esconda o cartão. Os valores do exemplo são ilustrativos.
