Cartão de uma medida, comparada com a linha de base da pessoa. Duas opções de formato.

- **Opção A, número primeiro:** rótulo, valor grande, linha de base e diferença. Lê-se de relance; boa para uma grade de quatro cartões.
- **Opção B, linha de tendência:** `h7-vital--row`, com o gráfico dos últimos 7 dias contra a linha de base (tracejada). Mostra a tendência, que é o argumento do projeto; ocupa a largura toda.

Quem usa fornece rótulo, valor, unidade, linha de base, diferença e estado. O cartão não muda de fundo, porque texto só fica sobre Deep Blue, Electric Blue ou branco. O gráfico usa a cor do texto; o estado fica no selo. Escolha uma das opções por tela; não misture.
