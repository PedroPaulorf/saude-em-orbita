Telas dos dois check-ups: uma pergunta por etapa.

À esquerda, uma etapa do check-up de saúde (Field). À direita, uma etapa do check-in comportamental (ScaleInput), com o aviso de que é autorrelato. Os dois fluxos são separados e têm contadores próprios. Cada etapa tem uma pergunta, um campo e os botões Back e Next; nada de formulário longo.
