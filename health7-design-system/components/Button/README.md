Botão de ação, em quatro variantes.

- `h7-btn--primary` (Neon Yellow, texto Deep Blue): a ação principal da tela. Uma por tela.
- `h7-btn` sem modificador (branco com borda): ações secundárias, como voltar.
- `h7-btn--inverse` (cor do texto, invertida): só para o que vai ao solo, como enviar o relatório.
- `disabled`: enquanto a etapa não está completa.

Quem usa fornece o texto (verbo no imperativo, em inglês) e, se quiser, um ícone de 14px antes dele. Altura mínima de 44px. Use `h7-btn--block` para ocupar a largura do contêiner. Não ponha dois botões amarelos lado a lado.
