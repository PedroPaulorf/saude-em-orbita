Selo com o estado de uma medida em relação à linha de base da pessoa.

- Dentro da linha de base: `h7-badge`.
- Atenção: `h7-badge--attention`.
- Sinalizado para o solo: `h7-badge--flagged`.

Sempre com ícone e palavra; nunca só a cor. Os três estados diferem por claridade, então continuam legíveis em tons de cinza. Quem usa escolhe o estado; o texto e o ícone são fixos. Atenção usa Neon Yellow; sinalizado usa Martian Red com texto branco. Não crie um quarto estado.
